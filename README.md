## Introduction

This website serves as a personal portfolio and a platform to share my projects, skills, and contact information. It is designed to be visually appealing and user-friendly, with a dark and light mode toggle for better user experience.

## Features

- **Dark and Light Mode Toggle**: Users can switch between dark and light themes.
- **Interactive Loader**: A unique loading animation that engages users.
- **Modal Image Viewer**: Clickable image that opens in a modal for a better view.
- **Responsive Design**: Optimized for various screen sizes and devices.
- **Sidebar Navigation**: Quick links to my social media profiles and more information.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and dynamic content.
- **Particles.js**: For the particle background effect.
- **FontAwesome**: For icons.

## Setup

To set up this project locally, follow these steps:

1. Clone the repository:
    ```sh
    git clone https://github.com/medjahdi/your-repo-name.git
    ```
2. Navigate to the project directory:
    ```sh
    cd your-repo-name
    ```
3. Open `index.html` in your preferred web browser.

## Usage

- Click on the image to view it in a modal.
- Use the toggle switch to change between dark and light modes.
- Explore the sidebar for quick links to my social media profiles.
